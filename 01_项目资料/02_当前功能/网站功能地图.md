# 网站里面有哪些功能

核验日期：2026-10-24。依据本地源码、路由、数据库模型及隔离测试整理；不代表线上站点或真实用户数据已验证。

产品主线是：登录 → 选考试/难度 → AI 出题或选择题库 → 组成练习套题 → 计时作答 → 查看结果与学习分析。

## 用户看到的页面

| 页面入口 | 用户能做什么 | 实际代码入口 | 当前判断 |
|---|---|---|---|
| `/` | 了解产品、选择界面语言、进入登录 | `apps/web/src/components/routes/LandingPage.tsx` | 默认中文，保留英语/印尼语切换 |
| `/login`、`/forgot-password`、`/setup-avatar` | 邮箱账号登录/注册、重置密码、设置头像 | `apps/web/src/routes/`、`components/sign-in-form.tsx`、`packages/auth` | 本地临时账号的注册/登录/头像已实测；真实邮箱投递与找回密码仍待验收；Google 登录默认不启用 |
| `/dashboard` | 学习概览、最近练习、精选内容、下一步入口 | `apps/web/src/routes/dashboard.tsx` | 首页精选已修正为仅展示公开外语内容 |
| `/generate` | 选考试、阅读题型、难度和数量，使用平台 AI 生成题目；高级用户可自带 Key | `apps/web/src/components/routes/GeneratePage.tsx`、`packages/api/src/routers/ai.ts` | 平台额度、预留结算和队列代码存在；真实模型调用未验证 |

## 考试、题型与真实能力

国内版仍保留 8 类语言考试：IELTS、TOEFL、JLPT、TOPIK、Goethe、DELE、TOAFL、HSK。服务中文用户不代表只能练英语；小语种与 HSK 暂按低优先级保留。

当前新出题目录只开放阅读，保留 20 种语言题型，包括选择、填空、同义词、语法、篇章匹配、汉字读音等。数据库里有其他科目定义，不等于听力音频、口语录音和评分流程已完成。本项目生成题为练习内容，不能据此宣称为官方真题或完整官方考试模拟。

界面文字与学习内容分开：导航/提示默认中文；题干、选项及学习目标语言保持原文。旧 CPNS 评分、prompt 和数据结构继续保留以兼容旧记录，不进入新目录。

## 工程与数据地图

| 位置 | 负责什么 | 主要依赖 |
|---|---|---|
| `apps/web` | React 19、Vite、TanStack Router 前端 | 浏览器、后端 HTTP |
| `apps/server` | Hono HTTP 服务、认证挂载、tRPC、健康检查 | PostgreSQL、Redis、SMTP |
| `packages/api` | 题库/套题/练习/统计/角色/额度业务与后台队列 | Drizzle、BullMQ |
| `packages/ai` | provider、生成 schema、提示词、多步骤生成与自检 | 服务器配置的 AI 服务 |
| `packages/db` | PostgreSQL schema、迁移、查询、参考数据 | PostgreSQL；本次未执行迁移或 seed |
| `packages/auth` | Better Auth 账号与会话 | 数据库、服务端密钥 |
| `packages/ui` | shadcn 组件、主题 token、全局样式 | 前端共享 UI |
| `packages/env` | 前后端配置校验 | `.env`，真实配置不提交 Git |
| `deploy`、`scripts` | 部署配置及隔离本地环境脚本 | Docker/Bun 等；存在脚本不代表当前已启动 |

正式账号、题目、作答、生成任务与积分均以 PostgreSQL 为业务数据来源。浏览器存储用于主题、界面语言和本地交互状态，不能代替服务端持久化验证。
