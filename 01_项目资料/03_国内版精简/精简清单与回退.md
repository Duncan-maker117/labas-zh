本次只做产品定位收敛、上游依赖清理和已复现的小范围修复；没有写入真实数据库、部署或推送代码。

| 内容 | 本次处理 | 为什么 |

| WhatsApp / Discord 社群、Rogasper Learning | 移除公共导航入口及不再使用的社群组件与链接配置 | 不属于当前国内学习流程 |

| CPNS 考试选项、TIU/TWK/TKP 科目、情境判断题型 | 从当前共享考试目录中移除 | 阻止公考选项继续出现在外语题库筛选器中 |
| CPNS 默认发现与推荐 | 题目、套题、阅读材料、组卷候选及首页精选默认排除 | 不让已有公考数据继续混入外语内容流 |

| `index.html` 印尼语标记、原站域名、英文介绍 | 改为中文初始文案与本地预览图片路径 | 页面脚本执行前也不显示原站定位 |
| 原站静态 sitemap 和 robots 中上游地址 | 移除静态旧清单与上游 Sitemap 声明 | 不再给搜索引擎提交别人的域名 |

| 上游 Blog API 默认地址 | 改为默认未配置；启用时必须显式配置自己的地址、slug 和 key | 不因开启博客而自动连接原作者接口 |
| 关闭博客后旧详情链接仍预取接口 | 加入 `VITE_BLOG_ENABLED` 判断 | 关闭内容模块时减少意外后台请求 |
| PWA 安装介绍 | 改为中文、设置 `zh-CN` | 安装入口与中文站定位一致 |

## 保留及原因

- **核心学习能力**：登录、题库、套题、计时作答、结果、历史、学习分析、平台 AI、用量治理和管理员功能。
- **外语考试**：保留英语、日语、韩语、德语、西语、阿语、HSK；没有按国别粗暴删除学习内容。
- **界面语言切换**：默认中文，保留已有切换能力，避免破坏前次确认的功能。
- **历史数据与旧地址**：CPNS 的数据库模型、schema/prompt、答题与评分兼容代码保留。旧 `/cpns/*` 由父路由重定向；按 ID 查询旧题/套题及历史成绩继续遵守原权限。
- **高级 BYOK**：用户自备 Key 的高级设置保留；普通用户默认使用平台 AI。
- **博客能力**：默认关闭，未来有中文内容与自有服务再启用；没有为了占位新增 CMS。
- **许可证和作者来源**：保留 LICENSE，历史审计标明来源。界面精简不代表改变现有源码授权。
- **Google 字体/图标**：目前仍有 Google Fonts 依赖，Material Symbols 承担大量图标；直接删除会让页面显示图标英文名称。需要单独改成本地资源并做视觉验收。

## 配置与影响范围

只更新示例配置；没有修改真实 `.env`。如果以后启用博客，需同时配置 `VITE_BLOG_ENABLED=true` 和自己的 `BLOG_API_URL`、`BLOG_PROJECT_SLUG`、`BLOG_API_KEY`。这些开关不构成支付或会员。

默认列表排除 CPNS，但显式传 `examTypeId=CPNS` 的历史接口查询仍保留。管理后台继续可以审阅所有历史内容；学习首页推荐仅返回公开外语内容。数据库没有删除、迁移或 seed。

## 如何撤回

本次按产品精简和资料整理分别保存本地提交；提交号见 Git 日志。撤回某一项时用 `git revert <提交号>` 保留历史，不用 reset/clean。

代码回退仅恢复代码和文档，不恢复数据库、账号或订单。此次没有更改数据库结构，因此不需要数据库逆向迁移。旧审计原件保留在原目录，归档副本可独立核对。
