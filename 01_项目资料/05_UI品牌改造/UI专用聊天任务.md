# UI 专用聊天：DUNCAN 品牌替换

## 用户需求

在 `D:\ai codex\外语学习网站` 项目下建立专门修改 UI 的聊天，将网站上对用户可见的网站名称、商标和品牌图标全部替换为用户提供的 **DUNCAN** 名称与标志。

原始标志：[DUNCAN_用户提供原始标志.png](../../02_品牌素材/DUNCAN_用户提供原始标志.png)。原件为用户附件副本；不要重画或擅自改变 D 字母、青色箭头及 DUNCAN 拼写。

## 本次修改边界

1. 先读项目与父级 `AGENTS.md`，核对 Git 状态、现有设计和品牌引用链；本次以品牌替换为主，不顺手重构业务。
2. 替换首页、登录/注册、找回密码、头像设置、桌面/移动导航、页头/页脚、学习首页、设置、帮助引导和管理员页面中的对外名称及品牌图像。
3. 检查初始 HTML、SEO/JSON-LD、浏览器 favicon、PWA 安装名称/图标、apple-touch 图标、Open Graph/Twitter 分享图，避免页面改了但浏览器标签或安装图标仍是旧品牌。
4. 检查用户实际能看到的插图或宣传素材是否嵌有旧标志；有则处理实际生效素材。源码历史归档中的旧名和未启用的历史演示不视作当前站点品牌入口，明确记录其范围。
5. 邮件模板的品牌名、邮件主题和欢迎/错误/引导文案一并核对；不向真实邮箱发送测试邮件，只使用已隔离的本地 Mailpit。
6. 保留当前中文默认、多语言切换和外语题目内容。优先集中管理品牌常量和素材入口，避免后续再全仓库搜替换。
7. `@labas/*` workspace 包名、数据库名称/表名、浏览器存储键、加密存储及内部兼容标识继续保持兼容，不能用全局字符串替换破坏账号或历史数据。LICENSE 与上游历史来源记录保留。
8. 不改真实 `.env`，不连接或修改正式用户库，不实现支付或会员，不推送、不部署。

## 当前运行环境

本地前端 `http://127.0.0.1:3001`，后端 `http://127.0.0.1:3000`；Docker 内仅为本项目隔离开发服务。当前前端与后端已启动；此前已实测注册、重新登录、头像完成和进入学习首页。

本次如需查看登录后的页面，可以在隔离开发环境使用精确标记的临时测试账号，验证后清理本次测试记录，不更改已有用户密码、管理员角色或真实数据。

## 交付要求

- 完成实际素材与代码替换，不能只改导航文字或交付一份方案。

- 运行相应类型检查/构建与 `git diff --check`；没有运行的检查不报告通过。
- 只提交本任务文件，使用本地署名 `Codex Local <codex@localhost>`，保留明确本地版本点；不得推送。
- 更新本目录中的完成记录和中文导航，列出素材位置、修改范围、验证结果与遗留项。

后续 UI 修改继续在这个专用聊天处理，保持同一项目根目录，不复制第二套网站源码。
